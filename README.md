# DataPipeline
Documentation on the DataStack Mapping Pipeline

## Local development

```bash
pip install mkdocs-material mkdocs-exclude
mkdocs serve
```

Open http://127.0.0.1:8000 in your browser. The site reloads automatically on file changes.

## Kill, rebuild and serve

```bash
pkill -f "mkdocs serve"; mkdocs build --strict && mkdocs serve
```

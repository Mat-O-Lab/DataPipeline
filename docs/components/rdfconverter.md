# RDFConverter

FastAPI microservice that orchestrates YARRRML parsing and RML execution to produce RDF knowledge graphs from raw data.

**Repo:** https://github.com/Mat-O-Lab/RDFConverter  
**Public API:** https://rdfconverter.matolab.org  
**Image:** `ghcr.io/mat-o-lab/rdfconverter:latest`

Internally coordinates `yarrrml-parser` (Node.js) and `rmlmapper-webapi` (Java, port 4000).

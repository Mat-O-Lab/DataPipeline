# Extractors

Input adapters that convert non-CSV data sources into the annotated JSON-LD / CSVW format the pipeline expects.

- [CSVToCSVW](csvtocsvw.md) — annotates CSV files with W3C CSVW metadata
- [OmeroExtractor](omeroextractor.md) — extracts metadata from OMERO microscopy servers
- [OpenBISmantic](openbismantic.md) — converts OpenBIS ELN entries to JSON-LD / RO-Crate
- [Ontop](ontop.md) — bridges SQL databases via OBDA/R2RML

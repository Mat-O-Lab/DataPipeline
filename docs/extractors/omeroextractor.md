# OmeroExtractor

Extracts structured metadata from OMERO microscopy servers and outputs JSON-LD, enabling microscopy data to enter the Mat-O-Lab pipeline.

**Repo:** https://github.com/Mat-O-Lab/OmeroExtractor  
**Public API:** https://metadata.omero.matolab.org  
**Image:** `ghcr.io/mat-o-lab/omeroextractor:latest`
